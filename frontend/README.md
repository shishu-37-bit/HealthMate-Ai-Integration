# HealthMate AI - Web Frontend 🩺

The modern, responsive web application client for **HealthMate AI**, built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**.

## Features
- ⚡ **Turbopack Powered**: Blazing fast hot module reloading and build times.
- 🎨 **Modern Aesthetics**: Tailored dark/light theming, ECG animations, and glassmorphic medical card previews.
- 🔄 **Redux Toolkit Integration**: State management for user sessions, vitals, report uploads, and AI insights.
- 🛡️ **Secure Session Handling**: Cookie-based authentication with automatic silent token refresh via Axios interceptors.

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
